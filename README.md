# 基于极值理论与 Copula 的多测点瓦斯联合预警

多测点瓦斯（甲烷）预警规则的**等误报率比较**实验框架。核心问题是：在**相同误报率**下、并且**把危险事件按类型分层（单点 / 多点耦合）**之后，常见的几条联合预警规则到底谁更好。

配套论文：《基于极值理论与 Copula 的多测点瓦斯联合预警：规则适用域与检出—及时性权衡》。

## 结论速览

1. **规则排序随危险段类型整体反转。** 合并统计得到「单点规则 B 全面占优」，拆开后在多点耦合事件上 **式(22) 计数规则 C22 显著更优**（非饱和基准、FAR\*=0.01：局部段 ΔFNR(B−C22) = −0.4662，耦合段 **+0.1604**）。
2. **那个优势是拿及时性换的。** 20 分钟窗内 B 漏 0.4% 的危险段，C22 漏 61.2%。
3. **不存在全面占优的规则。** 式(22) 的适用域是「测点响应近似同步（传播滞后 ≲ 5–10 分钟）、且危险以空间耦合为主」。

## 环境

Python 3.10+。依赖：

```
pip install -r requirements.txt
```

本机实测通过的版本：numpy 2.5.1 / scipy 1.18.0 / pandas 3.0.5 / matplotlib 3.11.1。

> Windows 提示：控制台默认是 GBK，脚本里出现的 `−`、`θ̂` 等字符无法编码。各脚本已内置 `sys.stdout.reconfigure(errors="replace")` 兜底，不会崩，但控制台上这些字符会显示成 `?`。数值结果在 CSV 里不受影响。

## 快速开始

```bash
python strict_pipeline.py    # 单数据集全流程，写 results/strict_results/（含 DET、MRL、参数稳定性图）
python run_30.py             # 30 组独立数据集 + Wilcoxon 配对检验，写 results/30_replicates/
python v20_cell.py 0.5 10 30 # 单个 (局部段占比, 传播滞后) 格跑 30 组，写 results/v20/
python v20_report.py         # 汇总 results/v20/ 下所有格子
```

所有参数**只在验证集上按目标 FAR 标定**，测试集只用于评价。60%/20%/20% 时间顺序划分，测试集不参与任何参数选择。

## 几个必须知道的口径

- **等误报率对齐**：所有参数只在验证集上按目标 FAR 选点，测试集只评价。测试集 FAR 因此有残差，`v18`/`v19` 就是专门查这个残差会不会把结论带偏的。
- **事件级 FNR 按危险段类型分层**：合并 FNR 只是两类的加权平均，符号由占比决定；只看合并数字会得出相反的结论。
- **Early-FNR**：漏报率口径（1.0 最差），窗口右端裁剪到危险段终点、起点前留 5 分钟提前容忍。5 / 10 分钟档在本数据上没有分辨力（小于数据自身的时间尺度），只有 20 / 30 分钟档可用。
- **`v19` 的 DET 插值属事后对齐**，不是可部署的标定流程；它的用途只是回答「FAR 严格对齐后排序是否还在」。
- 论文基准用的是 **amp = 0.40**（`SimConfig` 默认值是 0.78，落在饱和区，脚本里都显式覆盖了）。

## 已知限制

- 全部结论建立在**模拟数据**上。危险段类型比例（局部 50%）、段长、传播滞后、抬升幅度都是设定值，其中局部段占比直接决定合并口径下结论的**符号**（翻转点 25.6%）。
- 危险的标签与报警由同一个抬升过程驱动，这是模拟器的构造，真实数据上「匹配口径」需要重新评估。
- 固定 3 个测点，Copula 的可交换性假设也只在这个规模上验证过。
- PIT 均匀性检验在 2 个测点上有轻微偏离（K-S 0.0163 / 0.0168 对临界 0.0162），边缘模型有轻微误设。
